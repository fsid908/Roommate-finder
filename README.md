## ✨ Features

- 👤 Create and manage user profiles
- 🏠 Add and browse roommate listings
- 🔍 Search for potential roommates
- 🎯 Filter listings based on available criteria
- 🔗 REST API integration
- 📱 Responsive user interface
- 🗄️ MongoDB database integration
- ⚡ React-powered frontend
- 🛠️ Express.js backend API

## 🚀 Getting Started

Follow these steps to run the application locally.

### 1. Clone the Repository

```bash
git clone https://github.com/fsid908/Roommate-finder.git
cd Roommate-finder
```

### 2. Setup the Frontend

Open a **separate terminal** from the project root and run:

```bash
cd frontend
npm install
npm run dev
```

The Vite development server is typically available at:

```text
http://localhost:5173
```

Open this URL in your browser to access the application.

> If your `package.json` uses different scripts or ports, follow the configuration in your project.
